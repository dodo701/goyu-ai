## 2025-02-15 - React Component Definition Inline Anti-Pattern\n**Learning:** The `EnhancedChat` and `Chat` components are missing memoization around functions like `submit` and their `onChange` handlers, which could cause unnecessary re-renders. More importantly, `Page` contains very large components like `Home` and `EnhancedChat` which themselves are rendering functional props inside mapping loops instead of extracting them. Also, the `Page` component currently doesn't wrap `go` or `newConversation` with `useCallback`, leading to `Home` re-rendering whenever the main page state changes.\n**Action:** Use `useCallback` to memoize functions passed as props to child components (e.g., `newConversation`, `updateConversation`, `go`) and wrap pure UI components (`Home`, `Panel`) in `React.memo` to prevent unnecessary re-renders when parent states change, especially in a root `Page` component handling global navigation state.
